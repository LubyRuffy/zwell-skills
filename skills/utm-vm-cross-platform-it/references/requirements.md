# 宿主与来宾前置条件

- **macOS 宿主**：确认 UTM 与 `utmctl`，以及项目编排入口所需的权限和工具。首次使用具体 VM 时核对后端、UUID、来宾身份与可用通道。
- **Linux 来宾**：运行时满足项目要求。优先使用已启用的 SSH，系统动作如需提权则验证现有授权的 `sudo -n` 或经批准的 stdin 路径。QEMU Guest Agent 只有在实际验证后才能作为备选。
- **Windows 来宾**：复用既有 OpenSSH 或 WinRM。WinRM 使用已批准的认证、传输和网络边界；默认沿用当前安全配置。Go 项目直接用 Go 客户端，具体系统动作按需使用已有管理员授权。分发制品时校验文件哈希和目标路径。
- **macOS 来宾**：优先使用已配置并验证主机密钥的 Remote Login。原生 GUI 用例还需要来宾当前的可用 GUI 会话、项目 runner 和独占资源。预先核对所需的带外通道及其能力，见 [Mac 来宾恢复](macos-recovery.md)。

首次提供来宾入口时，将集成测试做成显式 opt-in，区分启动、传输、认证、用例及清理失败。每条远程执行应能回传 stdout、stderr、退出状态和取消后的可判定结果。
